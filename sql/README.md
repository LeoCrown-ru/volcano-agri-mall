# SQL 脚本目录

本目录存放火山石板岩特色农副产品电商系统（基于 RuoYi-Cloud 改造）的全部 SQL 脚本。

> **重要提醒**：除 `shop_cloud.sql` 外，其余脚本均已于 2026-08-29 在本地环境执行过，当前 `shop_cloud` 数据库已是最新状态。
> **不要重复执行**，否则会因主键重复或数据重复而报错。这些脚本的作用是**留档**与**换环境重建**。

## 一、文件清单与执行顺序

### 原始数据库备份

| 文件 | 说明 |
| --- | --- |
| `shop_cloud.sql` | 项目自带的数据库导出文件（改造前的初始状态），用于重建环境时导入 |

### 毕设改造脚本（按执行顺序排列）

| 顺序 | 文件 | 作用 |
| --- | --- | --- |
| 1 | `trace_sql.sql` | 创建 `cms_product_trace` 商品溯源信息表 |
| 2 | `agri_products.sql` | 第一批农副产品与分类数据（石板大米等） |
| 3 | `agri_products_add.sql` | 第二批商品补充 |
| 4 | `agri_products_fix.sql` | 商品信息修正（名称、价格、图片路径等） |
| 5 | `cleanup_old_data.sql` | 清理改造前的旧商品、旧分类及关联的订单、购物车、评价数据 |
| 6 | `reorganize_categories.sql` | 分类重组为 5 个顶级分类（石板大米、杂粮谷物、菌菇山珍、蜂产品、山货坚果） |
| 7 | `agri_products_expand.sql` | 第三批商品扩充，最终形成 34 个商品 |
| 8 | `trace_batch.sql` | 为 34 个商品批量生成溯源信息（按分类匹配产地、批次、生长记录、加工信息） |
| 9 | `promo_activities.sql` | 促销活动配置（活动 3201 / 3202 / 3203 及关联商品） |
| 10 | `fix_banner.sql` | 首页轮播图替换为农副产品图片 |
| 11 | `order_del_flag.sql` | 订单表增加 `del_flag` 字段（顾客侧软删除，后台仍可见） |
| 12 | `cleanup_test_orders.sql` | 清理测试订单（可选，视需要执行） |

## 二、换环境重建数据库的步骤

1. 用 Navicat 新建数据库 `shop_cloud`（字符集 `utf8mb4`），导入 `shop_cloud.sql`
2. 按上表顺序依次执行脚本 1 至 11（脚本 12 视需要执行）
3. 确认 `cms_product` 表有 34 条记录、`cms_product_category` 有 5 条记录、`cms_product_trace` 有 34 条记录
